about

Hello, I'm Pouya.

P

I've spent the last few years turning fuzzy mockups into resilient CSS — the kind that works at every width, in every browser, without anyone needing to explain the rules.

My craft is mostly layout and typography: flex, grid, custom properties, and spacing systems that scale. I care about the things users feel but rarely see — line-height, focus rings, the weight of a hover state.

Outside of code I write about CSS, mentor junior devs, and drink too much espresso. I believe good CSS is invisible when it's right and obvious when it's wrong.

— Pouya
