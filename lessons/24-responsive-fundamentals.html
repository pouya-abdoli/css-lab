lesson 24 · interactive

One site, every screen.

The same HTML ships to a phone, a laptop and a wall-sized monitor. Responsive design is the art of making it fit all three — by adding from mobile up, subtracting from desktop down, letting layouts flow, and choosing units that scale.

01 · mobile-first design

Start small, add with min-width

Write the base styles for the smallest screen, then add complexity as room appears: @media (min-width: …). Drag the viewport — the highlighted queries are the ones currently active.

02 · desktop-first design

          
Start rich, subtract with max-width

          

            The older habit: build the full desktop, then remove as space
            shrinks using @media (max-width: …). Same
            result, opposite direction — and usually more overrides.

03 · fluid layouts

          
No breakpoints, just flow

          

            Percentages and flexible tracks adapt continuously — every
            pixel of width, not just past thresholds. Compare: a fixed 380px
            image overflows the small frame; the fluid one never does.

04 · responsive units

          
Units that scale with the screen

          

            vw tracks the viewport,
            rem tracks the user's font setting, and
            clamp(min, preferred, max) gives you fluid

05 · field notes

          
Cheat codes from lesson 24

        

        

          

            

              

            

            
mobile-first = add

            

              Base = smallest screen;
              min-width queries layer on complexity.
              Fewer overrides, clearer priorities, happier phones.
            

            
↳ hover: room appears, columns appear

          

          

            

              

            

            
desktop-first = subtract

            

              Base = the full layout;
              max-width queries strip it down. Works,
              but every query is a correction, not an addition.
            

            
↳ hover: the grid collapses

          

          

            

              

            

            
fluid = continuous

            

              Percentages and fr adapt at every width, not just past
              breakpoints. Fluid grids + a few queries = coverage of all
              screens.
            

            
↳ hover: it stretches smoothly

          

          

            
clamp()

            
clamp = guardrails

            

              clamp(min, preferred, max): fluid in the
              middle, safe at the edges. The default for modern heading sizes.
            

            
↳ hover: it grows, within limits
