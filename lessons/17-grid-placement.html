lesson 17 · interactive

Items don't flow here. They're placed.

Lesson 16 drew the map; this lesson drives on it. Every grid has numbered lines — columns and rows — and four numbers (start / end on each axis) tell an item exactly where to sit. grid-column and grid-row are the shorthand; the -start / -end properties are the longhand.

01 · the numbered lines

Count the gaps, not the cells

Grid lines are numbered from 1 at each edge — columns in blue across the top, rows in orange down the side. Click any cell and read its address: the four line numbers that surround it.

how numbering works


            

              4 columns → lines 1–5. 3 rows → lines 1–4. An item spanning two
              columns sits between, say, line 2 and line 4. Negative numbers
              count from the end: -1 is always the
              last line.
            

          

        

      


      
      

        

          
02 · grid-column

          
Horizontal address: start / end

          

            grid-column: 2 / 4 means "start at column
            line 2, stop at line 4" — a span of two tracks. Drag the lines and
            watch the item stretch. -1 jumps to the
            far edge.

03 · grid-row

          
Vertical address: same game, rotated

05 · field notes

          
Cheat codes from lesson 17

        

        

          

            

              

                1234
              

            

            
lines, not cells

            

              Placement counts the numbered lines (the gaps' edges),
              starting at 1. N tracks → N+1 lines. Addresses are always start /
              end.
            

            
↳ hover: the lines light up

          

          

            

              

                
              

            

            
span = end − start

            

              2 / 4 spans two tracks.
              span 2 says the same with one number.
              The item stretches; the grid doesn't reflow.
            

            
↳ hover: span 2 → span 4

          

          

            

              

            

            
-1 = the last line

            

              Negative numbers count backwards from the end.
              1 / -1 = "the whole track", and it
              survives template changes.
            

            
↳ hover: grab the full row

          

          

            

              

                grid-column: 1 / 3;= column-start: 1; column-end: 3;
              

            

            
shorthand = longhand

            

              grid-column packs start/end into one line; grid-row does the same
              vertically. The four -start/-end props are the expanded spelling.
            

            
↳ hover: both spellings glow
