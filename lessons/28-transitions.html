lesson 28 · interactive

State changes deserve motion.

Without transitions, CSS state changes teleport: hover snaps, toggles jump. A transition interpolates the in-between frames — four knobs control it: property, duration, timing-function, delay.

04 · transition-delay

          
The stagger

          

            Delay waits before the trip starts. Increment it per element and you
            get the stagger — the cascade behind every polished menu,
            grid reveal and loading sequence. Set the step, press run.
          

        

        

          

            

              
              
the cascade

            

            

              

                

                

                

                

                

                

              

              

                
                
              

            

          

          

            

              

                0.08s
              

              
            

            

            

              In real code:
              transition-delay: calc(var(--i) * 80ms)
              with an --i per item. Small steps
              (60–120ms) read as rhythm; big ones read as lag.
            

          

        

      


      
      

        

          
05 · field notes

          
Cheat codes from lesson 28

        

        

          

            

            
glide, not teleport

            

              A transition interpolates between states. Declare it on the
              element before the change happens — it watches for value
              flips.
            

            
↳ hover: the morph

          

          

            

              

            

            
150–300ms sweet spot

            

              Under 100ms feels instant; over 500ms feels slow. Most UI feedback
              lives at 150–300ms. Duration is a feeling, not a number.
            

            
↳ hover: the slow fill

          

          

            

            
ease-out for entrances

            

              Things entering the screen should decelerate (ease-out); things
              leaving can accelerate (ease-in). cubic-bezier > 1 = spring.
            

            
↳ hover: the overshoot

          

          

            

              

            

            
stagger = delay × index

            

              60–120ms steps turn a simultaneous flip into a cascade. The single
              cheapest way to make UI feel designed.
            

            
↳ hover: the wave
