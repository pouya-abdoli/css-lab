lesson 40 · interactive

Dark mode is a token swap.

Done right, dark mode is never "restyle every selector." You define semantic tokens once, components read the tokens, and a theme is just a different set of token values — applied automatically via prefers-color-scheme or manually with a data-theme attribute.

02 · CSS variables as a theme system

          
Semantic tokens, not hex soup

          

            Components never reference raw hex — they read semantic names
            (--t-surface,
            --t-text). Each theme is just a block that
            redefines those names. Same markup, two skies.

03 · manual switching

          
One attribute flips everything

          

            Put the theme on a data-theme attribute
            and override the tokens under
            [data-theme="dark"]. Toggling one
            attribute re-skins the whole app. Persist it in localStorage.

04 · the recommended pattern

          
Default to the OS, allow override

          

            Best practice: start on auto (follow the OS), let the user
            pick light/dark, and remember it. Three states, one attribute. Try
            all three — auto tracks your OS live.
