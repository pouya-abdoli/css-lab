03 · box-sizing

          
Same CSS, two different boxes

          

            Both boxes get the identical width, padding and border. Only
            box-sizing
            differs. content-box: width = content only.
            border-box: width = the whole visible box — content shrinks

05 · margin

          
Invisible space — with a trick

          

            Margin is transparent and pushes neighbours away. But stack two
            boxes and their vertical margins collapse: the gap is the
            bigger one, not the sum. Drag and watch the browser do math you
            didn't ask for.

Cheat codes from lesson 06

        

        

          

            

              

                

              

            

            
the stack, inside-out

            

              Content → padding → border → margin. Every CSS layout question is
              eventually a question about which layer is misbehaving.
            

            
↳ hover: the layers inflate

          

          

            

            
padding vs margin

            

              The background paints through padding — it's part of the
              box's body. Margin is transparent forever: pure distance
              between boxes.
            

            

              ↳ hover: padding swells inside the frame
            

          

          

            

              * { box-sizing: border-box; }
            

            
border-box everywhere

            

              With border-box, width means the width
              you see. Padding & border squeeze the content instead of
              stretching the box. Ship the one-liner.
            

            
↳ hover: the fix lights up

          

          

            

              

            

            
margins collapse

            

              Stacked vertical margins merge to the bigger one: 40px + 30px
              ships a 40px gap. Surprising, ancient, and everywhere. Horizontal
              margins never collapse.
            

            
↳ hover: the gap collapses
