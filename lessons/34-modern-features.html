The features that shipped.

The last few years of CSS delivered more power than the previous decade: :has() selects parents, :is()/:where() group with control over specificity, aspect-ratio and object-fit tame media, color-mix() blends colors, and nesting is finally native. All live, all in your browser today.

01 · :has()

The parent selector, at last

CSS could never style an element based on its children — until :has(). Check a box and the whole card lights up, with zero JavaScript. The selector reads: "a card that has a checked input".

              :has() composes:
              form:has(:invalid) shows an error state,
              .nav:has(a:hover) highlights a menu.
              It's a query, not a state.
            

          

        

      


      
      

        

          
02 · :is() · :where()

          
Grouping, with a specificity dial

          

            Both group selectors. The difference:
            :is() takes the highest specificity
            of its arguments; :where() takes
            zero. Toggle the competing rule and watch :where lose while
            :is holds.
          

        

        

          

            

              
              
same grouping, different weight

            

            

              

                

                  :is() · 0,1,1
                  
Heading via :is(h4)

                  

                    keeps its blue — specificity 0,1,1 beats the 0,0,1
                    competitor
                  

                

                

                  :where() · 0,0,1
                  
Heading via :where(h4)

                  

                    loses to the later plain h4 rule — :where adds 0 specificity
                  

                

              

              

                
              

              

                competitor off — both headings blue
              

            

          

          

            

            

              Use :where() when you want a sensible
              default that any later rule can override;
              :is() when the group should carry real
              weight.

06 · field notes

          
Cheat codes from lesson 34

        

        

          

            

              

            

            
:has() = parent selector

            

              Style an element by what it contains. Forms, cards, navs — all can
              now react to descendants without JS.
            

            
↳ hover: the parent lights up

          

          

            

              
:is() 0,1,1 · :where() 0,0,0

            

            
:is vs :where

            

              Same grouping, different specificity. :is takes the max of its
              args; :where takes zero so it's always overridable.
            

            
↳ hover: the weights show

          

          

            

              

            

            
object-fit tames media

            

              cover crops, contain letterboxes, fill distorts. Pair with
              aspect-ratio for consistent media boxes, object-position to aim
              the crop.
            

            
↳ hover: the crop zooms

          

          

            

              

            

            
color-mix blends live

            

              Tints, shades, hover states — all computable in CSS now. Nesting
              makes the whole thing read like the DOM.
            

            
↳ hover: the blend pops
