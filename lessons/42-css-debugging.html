lesson 42 · interactive

DevTools is your X-ray.

When CSS misbehaves, the answer is always in DevTools: inspect to see which rule won, computed for the final value, the box model for space, the flex/grid inspectors for layout, and responsive mode for every screen. This lesson rebuilds each panel so you know exactly where to look.

01 · inspect element

Which rule actually won?

Click any element. The styles pane lists the rules that matched — the winner solid, the losers struck through. That strikethrough is the single most useful signal in all of CSS debugging.

07 · CSS debugging

          
The usual suspects

          

            Most "CSS is broken" is one of: a typo'd property (silently
            ignored), a missing unit, a later rule overriding, or a stray
            !important. Toggle each bug and see how

08 · field notes

          
Cheat codes from lesson 42

        

        

          

            

            
strikethrough = lost

            

              In the styles pane, a struck declaration matched but lost the
              cascade. The first solid one for a property is what's rendering.
            

            
↳ hover: the outline appears

          

          

            

              

            

            
box model explains gaps

            

              "Why the gap?" is almost always margin/padding. The rings show
              exactly where the space lives.
            

            
↳ hover: padding grows

          

          

            

              

            

            
inspectors show the skeleton

            

              Flex badges + axis arrow, grid line numbers. If layout's wrong,
              the overlay shows whether it's the container or the items.
            

            
↳ hover: badges appear

          

          

            

              
colr: red; ⚠

            

            
typos are silent

            

              Invalid declarations are ignored with no console error. A property
              that "does nothing" is usually a typo or missing unit.
            

            
↳ hover: the warning
