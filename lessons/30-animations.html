Transitions react. Animations perform.

A transition needs a state change to fire. An animation runs on its own: a script of frames (@keyframes) plus a director's note (animation) controlling duration, delay, repeats, easing and what happens before & after.

K · EYFRAMES · R · UN · F · OREVER

no hover, no click — it just runs…

01 · @keyframes

The script of frames

A keyframe rule is a timeline written in CSS: percentages → styles. Swap the script and the same box performs a different move. The browser interpolates everything in between.

              0% = from, 100% = to. Middle stops (45% here) create the
              personality. Keyframes can animate any animatable property —
              transform, opacity, color, even grid tracks.

06 · field notes

          
Cheat codes from lesson 30

        

        

          

            

            
keyframes = script

            

              Percentages → styles; the browser plays the in-betweens. Name it,
              then cast it with animation-name.
            

            
↳ hover: the bounce loops

          

          

            

              

            

            
first time = duration

            

              In the shorthand, the first time value is duration, the second
              delay. Everything else can be in any order.
            

            
↳ hover: the fill sweeps

          

          

            

            
alternate + ease-in-out

            

              The universal smooth-loop recipe: ping-pong direction with
              symmetric easing. Shimmers, breaths, pulses.
            

            
↳ hover: it ping-pongs

          

          

            

            
fill = the edges

            

              backwards applies frame 0 during the
              delay; forwards keeps the last frame
              after the end; both = the sane default.
            

            
↳ hover: delayed, then held
