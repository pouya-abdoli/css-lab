HTML builds the page. CSS makes it beautiful.

CSS — Cascading Style Sheets — is the design language of the web. It takes plain documents and gives them color, shape, rhythm and motion. In this lesson you'll see exactly what CSS does, where it lives, how the browser loads it, and how to write your first rule.

HTML = the nounsHeadings, paragraphs, links, buttons. It decides what things are and in what order — nothing about how they look.
CSS = the adjectivesColors, sizes, fonts, spacing, motion. It decides how things look — without touching the content itself.

06 · field notes

          
Cheat codes from lesson 01

        

        

          

            

            
what css does

            

              Color, typography, spacing, component design, layout and motion.
              Without CSS, every website on earth looks like a 1993 document —
              because that's all HTML provides.
            

            
↳ hover: paint arrives

          

          

            

              h1
               { 
              color: red;
               }
            

            
the syntax pattern

            

              selector { property: value; } — selector
              picks the element, declarations change it. Miss a
              ; and the next declaration silently
              breaks.
            

            
↳ hover: the rule assembles

          

          

            

              inline — style="…"
              internal — <style>
              external — styles.css ✓
            

            
three homes for css

            

              Inline is for emergencies, internal for prototypes,
              external for everything real. One cached stylesheet can
              style a thousand pages.
            

            
↳ hover: the winner emerges

          

          

            

              <link rel="stylesheet"> → 🖥
            

            
loading order

            

              Put <link> in
              <head>. CSS is render-blocking on
              purpose — the browser waits for it so users never see a flash of
              unstyled content (FOUC).
