lesson 27 · interactive

Components that hear their own box.

Media queries ask the viewport. Container queries ask the parent. A card in a sidebar and the same card in a main column can now style themselves differently — no classes, no JavaScript, no viewport involvement.

01 · @container

Two lines of setup, one query

Mark the parent with container-type: inline-size, then query it with @container (min-width: 380px). Drag the container — the card flips layout at 380px no matter what your window does.

03 · media vs container queries

          
Two different ears

          

            Left card obeys a media query — it only changes when your
            window crosses 1100px. Right card obeys a
            container query — it only changes when its box crosses
            380px. Resize the window AND drag the slider; watch each card mind
            its own business.

map vs furniture

            

              Media queries arrange the page; container queries arrange the
              pieces inside it. Both coexist happily in one codebase.
            

            
↳ hover: the container side lights up

          

          

            

              
container-type: inline-size

            

            
inline-size, not size

            

              inline-size (width) avoids layout loops;
              full size containment exists but rarely
              needed. Query what you actually respond to.
