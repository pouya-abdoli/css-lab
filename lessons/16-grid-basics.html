Flexbox is a line. Grid is a map.

Flexbox lays items along one axis. Grid draws both axes at once: you define the columns and rows first, then items pour into the cells. grid-template-columns and -rows are the blueprint; gap is the mortar.

01 · display: grid

The switch that draws a map

Flip it and the container stops flowing items in a line and starts placing them into cells. Without a template, grid auto-creates one column per… actually one row per item — the template is what gives it shape. That's the next section.

03 · grid-template-columns

          
Draw the columns first

          

            The most important property in grid. List the tracks:
            1fr is "one share of the free space",
            repeat(3, 1fr) is three equal shares,
            200px 1fr is a fixed rail plus liquid.
            Items flow into them automatically.

05 · gap

          
The mortar between cells

          

            Grid's gap works exactly like flex's: space
            between tracks only, never at the outer edges.
            column-gap for the vertical gutters,
            row-gap for the horizontal ones.

06 · field notes

          
Cheat codes from lesson 16

        

        

          

            

              

            

            
grid = two axes

            

              Flex thinks in lines; grid thinks in maps. Columns and rows
              exist before a single item arrives. Items pour into cells.
            

            
↳ hover: the map redraws

          

          

            

              

            

            
template-columns rules

            

              One value per track. repeat() is
              shorthand, fr is a share, px is a
              promise. The blueprint decides everything downstream.
            

            
↳ hover: 3 equal → 2:1

          

          

            

              

            

            
fr = free-space share

            

              Like flex-grow for tracks: 1fr 2fr gives
              the second track double the leftovers. Fixed tracks eat first, fr
              splits the rest.
            

            
↳ hover: the shares rebalance

          

          

            

              

                
              

            

            
gap = mortar

            

              Space between tracks only. Replaces every margin-grid hack, never
              collapses, never leaks to the edges. row-gap + column-gap or one
              gap.
            

            
↳ hover: the gutters breathe
