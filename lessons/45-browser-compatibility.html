lesson 45 · interactive · the finale

Ship for the browsers people have.

You can't test everywhere, so you detect instead of assume: read support data, probe with CSS.supports() and @supports, and build a base that works everywhere before enhancing. Compatibility isn't a blocker — it's a design constraint.

04 · progressive enhancement

          
Base works, then enhance

          

            Build a page that's fully usable with the simplest CSS, then layer
            enhancements on top. Toggle enhance: the base never breaks, the
            fancy parts are optional.
