On top? It's a contest.

When boxes overlap, the browser runs a quiet competition: z-index scores it, stacking contexts seal the rooms, and DOM order breaks the ties. Learn the rules — and why z-index: 9999 sometimes loses.

03 · why z-index sometimes doesn't work

          
The static silence

          

            The #1 z-index bug: the element is position: static. The
            amber box is positioned and scored; the blue one has a huge z-index
            but is static — so it stays buried. Flip it to relative and the
            number finally counts.

04 · the tiebreak: DOM order

          
No z-index? Later wins

          

            Both boxes are positioned, neither has a z-index. The browser shrugs
            and paints in HTML order — last one written, top one seen.
            Swap the order and watch pink and green trade places.

05 · field notes

          
Cheat codes from lesson 11

        

        

          

            

              

            

            
z-index needs a ticket

            

              It only works on positioned elements — or flex/grid items. On a
              static box, z-index: 9999 is a number
              written on a napkin.
            

            
↳ hover: the two trade places

          

          

            

              

                

                

                z:9999
              

            

            
contexts are sealed

            

              A child's z-index only competes inside its stacking
              context. Against the outside world, it rides on its parent's
              score. 9999 loses to 2.
            

            
↳ hover: the kid jumps, stays sealed

          

          

            

              

            

            
DOM order breaks ties

            

              No z-index anywhere? Paint order = HTML order. Later element on
              top. Swapping markup is a legitimate (if ugly) z-fix.
            

            
↳ hover: the queue reverses

the paint recipe

            

              Inside a context: root bg → negative z → block backgrounds →
              floats → inline text → positioned z:auto/0 → positive z. Memorize
              the ends, look up the middle.
