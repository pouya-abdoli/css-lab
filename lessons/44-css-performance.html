lesson 44 · interactive

Fast CSS is less CSS.

Performance is mostly subtraction: ship less unused CSS, minify what remains, inline the critical path, and animate only what the compositor can handle — transform and opacity. Five habits, each measurable.

S · HIP · L · ESS · R · UN · FASTER

most stylesheets are mostly waste…

01 · reduce unused CSS

Ship what the page uses

A typical stylesheet is mostly rules the current page never matches — dead weight parsed on every load. Audit it, purge the unused, and watch the payload drop.

audit & purge


            

              DevTools Coverage tab shows exactly which bytes ran. Purge
              per-page (or code-split) so each route ships only its own CSS.

04 · avoid expensive animations

          
Layout vs composite

          

            Animating left forces layout every frame;
            animating transform stays on the
            compositor. Same motion, very different cost.
          

        

        

          

            

              
              
same motion, different cost

            

            

              

                

                  

                  left → layout every frame
                

                

                  

                  transform → compositor only
                

              

              

                both move identically — one reflows the page 60×/sec
              

            

          

          

            

            

              Anything that changes geometry (width, top, left, margin) triggers
              layout. Prefer transform for movement, and keep animated subtrees
              small.
            

          

        

      


      
      

        

          
05 · transform & opacity

          
The compositor's two favorites

          

            transform and
            opacity skip layout and paint — the GPU
            just recomposites. Pick a property and see its cost class.
          

        

        

          

            

              
              
pick the property

            

            

              

                

              

              

                
                
                
                
              

              

            

          

          

            

            

              box-shadow & colors are paint (medium). width/top/left are
              layout (expensive). transform/opacity are composite (cheap) —
              reach for those first.
