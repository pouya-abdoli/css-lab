02 · repeat()

          
Write the pattern once

          

            repeat(4, 1fr) is four equal tracks
            without typing four values. And repeat takes patterns, not
            just single tracks:
            repeat(2, 1fr 2fr) writes four tracks in

03 · minmax()

          
Guardrails per track

          

            minmax(90px, 1fr) = "never below 90, grow
            if you can". Shrink the container: tracks hold the floor and the
            grid overflows instead of crushing its content. That's responsive
            design with zero media queries.

04 · auto-fit vs auto-fill

          
How many tracks fit?

          

            Both compute "as many minmax tracks as fit". The difference:
            auto-fill keeps the empty ones (reserved seats),
            auto-fit collapses them so your items stretch into the spare
            space. Three items, wide container — watch the right edge.

05 · grid-template-areas

          
Draw the layout in ASCII

06 · field notes

          
Cheat codes from lesson 18

        

        

          

            

              

            

            
fr = ratio

            

              Fixed tracks eat first; fr splits the leftovers by share. 1fr/2fr
              means "half as wide" at every screen size. Flex-grow's grid twin.
            

            
↳ hover: the ratio rebalances

          

          

            

              

            

            
repeat = pattern

            

              count × track(s). The track argument can be a list: repeat(2, 1fr
              2fr) = four tracks, alternating rhythm, two values typed.
            

            
↳ hover: 3 tracks → 6

          

          

            

              

            

            
minmax = guardrails

            

              Never below min, grow to max. Pair with repeat for fluid layouts
              that refuse to crush content. Overflow before collapse.
            

            
↳ hover: the floor holds

          

          

            

              

                
              

            

            
fit vs fill

            

              auto-fill reserves empty tracks; auto-fit collapses them so items
              stretch. For "cards that always fill the row", it's auto-fit.
            

            
↳ hover: phantoms vanish
