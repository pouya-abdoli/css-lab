calc() min() · max() clamp() var() rgb() · hsl() cheat-codes

lesson 33 · interactive

Functions turn CSS into a calculator.

Everywhere you'd write a static value, a function can compute one: arithmetic with calc(), comparisons with min()/max()/clamp(), variable lookup with var(), color mixing with rgb()/hsl(). They nest, they compose, they run at render time.

01 · calc()

Arithmetic inside values

calc() lets you do math where CSS normally wants a single number. Mix units freely — 100% − 40px is a perfectly legal width. Spaces around operators are required.

02 · min() · max()

          
Ceilings and floors, live

          

            min() returns the smaller argument — a
            responsive ceiling. max() returns the
            larger — a floor that holds when the viewport shrinks. Same
            viewport, opposite roles.

              The crossover point is where the two arguments are equal. For
              min(60vw, 500px) that's ~833px — below,
              60vw wins; above, 500px wins.
            

          

        

      


      
      

        

          
03 · clamp()

          
Floor · preferred · ceiling

          

            Three arguments: minimum, preferred, maximum. The preferred
            value is returned while it stays inside the guardrails; outside, the
            nearer rail wins. The one-liner for fluid typography.

04 · var()

          
Compose, don't duplicate

          

            var() isn't just for standalone values —
            it composes inside other functions. Below, three RGB channels
            are each a custom property; the color itself is built from a formula
            of variables.

05 · rgb() · hsl()

          
Two mental models of color

          

            rgb(r, g, b) mixes light channels (what
            screens emit). hsl(h, s, l) describes
            color the way humans talk about it: hue around the wheel, saturation
            (colorfulness), lightness (dark↔light). Pick a model and drag.
