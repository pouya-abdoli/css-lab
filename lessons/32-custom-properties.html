Variables that cascade.

CSS custom properties are like Sass variables but alive: they inherit, they cascade, they can be changed at runtime with one line of JavaScript, and every consumer updates instantly. The panel shows your page's current variables — pick a color anywhere and watch all three update.

01 · defining variables

Double-dash, one source of truth

Declare with --name: value inside any selector. The three consumers below all read the same --user-primary: a border, a background, an inset glow. Pick a color — they all update from the same source.

              Names must start with -- (two hyphens).
              The rest is your choice — --primary,
              --color-brand,
              --space-md. Convention over rules.
            

          

        

      


      
      

        

          
02 · using variables

          
var(  ) reads the value

          

            Wherever you'd write a value, write
            var(--name) instead. The browser resolves
            it at render time — so the same declaration stays correct even when
            the variable changes. Works anywhere a value goes: colors, sizes,
            shadows, even grid templates.
          

        

        

          

            

              
              
everywhere a value goes

              Sass variables are replaced at build time — once compiled, they're
              gone. Custom properties resolve at render time, which is
              why the same
              var(--scope-accent) declaration can mean
              three different colors.
            

          

        

      


      
      

        

          
04 · fallback values

          
The comma is the safety net

          

            var(--brand, #f07f4f) — if
            --brand is undefined, the value after the
            comma is used instead. Toggle the definition and watch the border
            and button color flip between defined and fallback.

              Fallbacks nest:
              var(--a, var(--b, red)) — if --a is
              missing, try --b, else red. Great for progressive theming.
