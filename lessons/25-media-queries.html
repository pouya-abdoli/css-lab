02 · breakpoints

          
Where the layout switches

          

            A breakpoint is just the width where a media query kicks in. The
            classics are 480 / 768 / 1024 — but the pro move is choosing them
            where your content breaks, not where a device happens to
            exist.

04 · orientation queries

          
Portrait vs landscape

          

            (orientation: landscape) is true whenever
            width beats height — phones rotated, laptops always. Rotate the
            device and see which query fires; your own window's answer is live
            too.
          

        

        

          

            

              
              
rotate the device

            

            

              

                

                  

                  

                

              

              

            

          

          

            
            

            

              Orientation is a ratio, not a rotation sensor: a narrow desktop
              window is "portrait". Use it for photo grids, games, fullscreen
              heroes.
            

          

        

      


      
      

        

          
05 · field notes

          
Cheat codes from lesson 25

        

        

          

            

              
@media (true) { … }

            

            
a query is a question

            

              The rules inside run only while the condition holds. Width,
              orientation, motion, hover, color-scheme — the browser answers,
              CSS adapts.
            

            
↳ hover: the condition glows

          

          

            

              

            

            
break at content

            

              480/768/1024 are habits, not laws. The correct breakpoint is where
              your layout breaks — find it by shrinking, not by
              memorizing phones.
            

            
↳ hover: a zone widens

          

          

            

              

            

            
3 layouts = 2 queries

            

              Base mobile + one min-width for tablet + one for desktop. Most
              sites ever built run on exactly this skeleton.
            

            
↳ hover: the sidebar appears

          

          

            

            
orientation = ratio

            

              width > height → landscape. No gyroscope involved. Laptops are
              always landscape; a tall narrow window is portrait.
            

            
↳ hover: the device rotates
