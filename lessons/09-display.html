02 · flex & grid

          
The layout engines

          

            Same six items, three engines. block stacks them.
            flex lays them along one axis and lets them share space.
            grid builds two axes at once — rows and columns.

03 · display: none vs visibility: hidden

          
Removed, or just invisible?

          

            Both hide box B. But visibility: hidden leaves its seat empty
            — C doesn't move. display: none removes it from the layout
            entirely — C slides up. The readout measures C to prove it.

04 · overflow

          
When content doesn't fit

          

            The box is 150px tall; the text is not. visible lets it
            spill. hidden clips it silently. scroll always shows a
            scrollbar. auto adds one only when needed — the polite
            default for scroll areas.

05 · field notes

          
Cheat codes from lesson 09

        

        

          

            

              

            

            
the three flow modes

            

              block stacks & fills. inline flows but ignores
              size. inline-block flows and takes width/height.
              Links are inline; divs are block; buttons behave inline-block.
            

            
↳ hover: the stack becomes a row

          

          

            

              

            

            
flex vs grid

            

              Flex = one axis, content can push sizes. Grid = two axes, you draw
              the tracks. Both take gap, both kill the
              margin hacks of old layouts.
            

            
↳ hover: the row snaps into a grid

          

          

            

              

            

            
none vs hidden

            

              display:none = removed, neighbours close
              the gap. visibility:hidden = invisible
              but the seat stays warm. Choose by whether layout should move.
            

            
↳ hover: B vanishes, space remains

          

          

            

              

            

            
overflow is a decision

            

              Content never "just fits" — you decide: spill (visible), clip (hidden), or scrollbars (scroll/auto). Auto only when needed.
            

            
↳ hover: the box clips its lines
