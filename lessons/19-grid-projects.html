05 · field notes

          
Cheat codes from lesson 19

        

        

          

            

              

            

            
areas = the wireframe

            

              Name the regions, draw the map, swap the map per breakpoint. HTML
              stays untouched; the layout is just a string.
            

            
↳ hover: desktop collapses to mobile

          

          

            

              

            

            
galleries = spans + dense

            

              Fixed auto-rows + a few span-2 heroes + dense backfilling =
              editorial rhythm without masonry libraries.
            

            
↳ hover: rows breathe

          

          

            

              

            

            
blogs = measure control

            

              Two columns for browsing, one for reading. The aside never
              disappears — the map just reorders it below the article.
            

            
↳ hover: focus mode engages

          

          

            

              

            

            
shops = auto-fit

            

              minmax(min, 1fr) inside auto-fit: cards wrap when cramped, stretch
              when spacious. Zero media queries, forever responsive.
            

            
↳ hover: the gutters widen
