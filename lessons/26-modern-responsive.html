min() max() clamp() min(90%, 1200px) cheat-codes

lesson 26 · interactive

Math is the new media query.

min(), max() and clamp() let CSS compare values live — no breakpoints, no JavaScript. The result recomputes on every resize. One line like width: min(90%, 1200px) replaces an entire media-query block.

01 · min()

The smaller one wins

min(a, b) evaluates both and returns the smaller — a ceiling that follows the viewport. Drag it: while 60vw is under 500px it wins; past that, the cap takes over.

03 · clamp()

          
Floor, preferred, ceiling

          

            clamp(min, preferred, max) = "grow with

04 · width: min(90%, 1200px)

          
The one-line responsive container

          

            90% on small screens (breathing room), 1200px on big ones (readable
            measure), and a smooth hand-off in between —
            zero media queries. This single line is on almost every
            professional site.
